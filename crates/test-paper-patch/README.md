An *experimental* test for gitpatcher by applying & rebuilding patches
for the [Paper](https://papermc.io/) minecraft project.

It is for internal use only, not for consumption by users.
Paper normally uses the [paperweight](https://github.com/PaperMC/paperweight)
plugin for the [gradle](https://gradle.org/) build tool.

The Paper patch system is the inspiration for this project.
Since Paper includes hundreds of patches, it makes an excellent test case.

This crate is useful for fixing the [excessive churn issue (#1)][excessive-churn-issue],
as the PaperMC patch system is already able to filter it out.q

[excessive-churn-issue]: https://github.com/Techcable/gitpatcher/issues/1
